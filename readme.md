# Photo Guessing

A small React game for matching photo sets to people.

## Modes

- **Creator** creates one page per person with three photo links and optional text.
- **Presenter** moves back and forward through the pages and ends the game.
- **Player** joins with a name and submits guesses that stay hidden until the game ends.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
